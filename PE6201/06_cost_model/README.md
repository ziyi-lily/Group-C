# Part 6 — Cost Model and result visualisation

- `PE6201_A2_Cost_Model.xlsx` contains the cost ledger, monthly model, sensitivity analysis, break-even analysis and cost levers.
- `PE6201_A2_Cost_Visualisation.ipynb` reproduces the charts and exports their underlying data.

The notebook reads the workbook from this folder and writes generated figures to `output/`, so it is portable after cloning the repository.
